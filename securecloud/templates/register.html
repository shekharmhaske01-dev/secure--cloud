What happens to your file

Your file is never stored as-is. It is segmented, each block is sealed with AES-256-GCM, and only the encrypted blocks are uploaded to object storage.

Encryption keys are managed with envelope encryption: one data key per file, wrapped by a key-encryption key held outside the database.
