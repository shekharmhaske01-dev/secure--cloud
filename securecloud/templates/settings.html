Configuration guidance

  1. Create a Neon project and enable object storage for the branch.
  2. Read the branch S3 endpoint and region from the Neon console (or run neon env pull) and set NEON_STORAGE_ENDPOINT_URL and NEON_STORAGE_REGION. Do not use the PostgreSQL connection string here — the database endpoint and the object-storage endpoint are different services.
  3. Create a credential with storage read/write scope and copy its access key id and secret into NEON_STORAGE_ACCESS_KEY_ID and NEON_STORAGE_SECRET_ACCESS_KEY.
  4. Create a private bucket and set NEON_STORAGE_BUCKET.
  5. Set SECURECLOUD_STORAGE_BACKEND=s3 (path-style addressing is applied automatically, as Neon Object Storage requires).
  6. Run python scripts/check_storage.py to verify connectivity.
