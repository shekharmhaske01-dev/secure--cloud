About deletion

Deleting a file removes every encrypted block object and the wrapped file key. The metadata record is only marked deleted once all objects are confirmed gone; if the provider refuses some deletions the remaining objects are recorded as a cleanup job and retried from the Settings page. Object storage may retain deleted objects in provider backups, versioning or snapshots, so deletion cannot be guaranteed to be irreversible at the provider level.
